# TextRPG v0.2 (Python, terminal)

La version Python du jeu, conservée comme référence : c'est la spécification d'origine de la
v1.0 web (formules, courbe d'expérience, contenu).

```bash
pip install -e ".[dev]"
python -m textrpg          # jouer dans le terminal
pytest                     # 32 tests
```

Voir [docs/AUDIT.md](docs/AUDIT.md) pour l'audit du prototype de 2022 et
[docs/VISION.md](docs/VISION.md) pour la vision du jeu reconstituée.
